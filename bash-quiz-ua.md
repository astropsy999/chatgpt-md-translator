#### Q6. Щоб назавжди видалити порожні рядки з файлу під назвою textfile, яку команду можна використати?

- [x] `sed -i '/^$/d' textfile`
- [ ] `sed '/^$/d' textfile`
- [ ] `cat textfile | sed '/^$/d`
- [ ] `sed -i 's/^$//' textfile`

[Довідка](https://www.gnu.org/software/sed/manual/sed.html#sed-regular-expressions)  
sed: sed — це редактор потоків. Редактор потоків використовується для виконання базових текстових перетворень на вхідному потоці.  
-i[SUFFIX]: Ця опція вказує, що файли потрібно редагувати на місці.  
'/^$/d': regex знаходиться між //. ^ — це початок рядка, $ — це кінець рядка. ^$ означає, що між початком і кінцем нічого немає.  
d: Видалити простір шаблону; негайно почати наступний цикл.  
Попередження: цей приклад не працюватиме в терміналі Mac через різні версії UNIX. Є спосіб змусити його працювати на Mac, додавши додатковий прапорець `-e`, або навіть просто `--` (знайдено на [StackOverflow](https://stackoverflow.com/questions/4247068/sed-command-with-i-option-failing-on-mac-but-works-on-linux)): `sed -i -e '/^$/d' textfile.txt`

#### Q18. Який результат цього коду?

```bash
VAR="/var/www/html/website.com/html/"
echo "${VAR#*/html}"
```

- [x] `/website.com/html/`
- [ ] `/html/website.com/html/`
- [ ] `/var/www/html/website.com/`
- [ ] Нічого не буде виведено на екран.

[Довідка]()  
Що тут відбувається, цитуючи специфікацію POSIX shell: `${parameter#[word]}`. Видалити найменший префікс, що відповідає шаблону. Слово буде розширено для створення шаблону. Розширення параметра призведе до параметра, з якого буде видалено найменшу частину префікса, що відповідає шаблону.  
Наприклад, `${VAR#?}` розширюється до значення $VAR з видаленням першого символу. А `${VAR#\*/html}` розширюється, щоб включити всі символи до і включно з текстом `/html`, який буде видалено з змінної, що призведе до виведення `/website.com/html/`.
